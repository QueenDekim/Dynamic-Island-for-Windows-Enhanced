# Windhawk API header for native preview builds

This copy of windhawk_api.h comes from the Windhawk 1.6 compiler
installation, maintained by ramensoftware:
https://github.com/ramensoftware/windhawk

Windhawk uses GNU General Public License version 3.0 (GPL-3.0).
The header is preserved for C++ toolchain compatibility when building
the *actual Windhawk Renderer* outside the Windhawk process. The
WH_EDITING mode provides placeholder settings functions; no private
Windhawk binaries are bundled in this repository.
